📋 Setup Checklist

  • 1️⃣
    Create Supabase projectsupabase.com → New project → run the schema.sql file from the repo in the SQL editor
  • 2️⃣
    Create Vercel projectvercel.com → Add New → Project → import driver-platform repo → set all env vars above
  • 3️⃣
    Run database schemaSupabase → SQL Editor → paste contents of supabase/schema.sql → Run
  • 4️⃣
    Create admin userSupabase → Authentication → Users → Invite user (admin email) → then in SQL editor run:

    UPDATE profiles SET role = 'admin' WHERE email = 'admin@company.com';
  • 5️⃣
    Enable RealtimeSupabase → Database → Replication → enable delivery_reports and driver_locations tables
  • 6️⃣
    Set custom domain (optional)Vercel → Settings → Domains → add client's domain
  • 7️⃣
    Test loginVisit the deployed URL → log in as admin → create a test driver → invite them → confirm they can log in
